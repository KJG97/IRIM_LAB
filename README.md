# ALLEX Digital Twin

Isaac Sim을 사용한 ALLEX 로봇의 Digital Twin 구현

## 주요 기능
- ROS2 Publisher/Subscriber 독립 제어
- 6축 관절 실시간 제어
- 외부 ROS2 토픽 구독
- 시스템 헬스 모니터링

## 사용법
1. Isaac Sim 실행
2. LOAD 버튼으로 로봇 로드
3. ROS2 Manager 초기화
4. Publisher/Subscriber 토글로 제어 모드 선택
